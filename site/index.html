What it is

A wallpaper that listens.

  • Your own picture

    Woofer animates the wallpaper you already love: a speaker cone, a ripple, a glitch, a heat haze. Or pick a generative background.

  • Any layer-shell compositor

    Hyprland, Sway, niri, river… Only Hyprland is tested so far, reports welcome.

  • Straight from PipeWire

    No cava, no extra process. FFT, bass, mids, highs, kick detection and a 16-band spectrum.

  • Quiet when it's quiet

    It draws only on frame callbacks, slows down after 2 s of silence, and pauses behind fullscreen windows.

  • Follows your theme

    With Caelestia, the wallpaper and Material You colours are followed live.

  • Live control

    woofer ctl preset ripple switches on the fly. No restart.

Install

Three commands to life.

From source, until packages exist (AUR planned). Needs a Wayland compositor with wlr-layer-shell, PipeWire and a Vulkan driver.

# Arch: sudo pacman -S --needed rust clang pipewire vulkan-icd-loader  (+ your Vulkan driver)
git clone https://github.com/Ybucaille/woofer && cd woofer
cargo install --path daemon --locked
mkdir -p ~/.local/share/woofer && cp -r shaders ~/.local/share/woofer/
woofer --wallpaper ~/Pictures/wall.jpg --preset glitch
woofer ctl preset synthwave     # switch on the fly
woofer ctl intensity 0.6

Autostart, Sway, Caelestia and every flag: README.

Make your own

One file. Your effect.

An effect is a single Shadertoy-style .glsl. The same file runs in the daemon, the Quickshell module and the browser preview. Bass, beat, spectrum and your theme colours come in as uniforms.

Read the shader contract 
// @name My Effect
// @description One line shown in the picker

void mainImage(out vec4 fragColor, in vec2 fragCoord) {
    vec2 uv = fragCoord / iResolution;
    uv += (uv - 0.5) * -0.02 * uBass * uIntensity;
    fragColor = vec4(wall(uv).rgb, 1.0);
}
